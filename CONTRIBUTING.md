# Contributing

Thank you for your interest in contributing. This project follows best practices inspired by ISO/IEC and TOGAF principles for change management, architecture governance, and quality assurance.

Please ensure:

- All changes are made via pull requests against feature branches.
- PR must include tests and update CHANGELOG if applicable.
- Critical changes require an architecture decision record (ADR) and approval by a maintainer.

CI will run linting, tests and build artifacts. For release to production (main/master), a designated reviewer must sign off.
